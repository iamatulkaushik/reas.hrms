# Revolution HRMS (Offline)

Offline HRMS for Indian (Haryana) labour law compliance. VB.NET WinForms on .NET 10, SQL Server Express on a server PC.

Everything is documented in [`docs/`](docs/README.md). Start with `docs/ROADMAP.md` and `docs/DECISIONS.md`.
Instructions for Claude Code are in [`CLAUDE.md`](CLAUDE.md).

Quick start for a developer PC: see "Getting started" in `docs/README.md`.
